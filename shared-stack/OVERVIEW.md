Lets agents on several Paseo daemons on one machine, each run by a different user account, take turns on one shared running dev stack. Agents join a queue; the agent at the front holds the stack, and its workspace's working tree, including uncommitted and untracked files but not ignored ones, is synced onto the stack's checkout so the stack reloads with its changes. Releasing the stack, or a hold that runs out, hands it to the next agent; when nobody holds it, the checkout returns to its own state. It requires Paseo 0.14.0 or newer on every daemon.

The queue lives in a folder shared by the accounts' group, by default `/srv/paseo-shared/shared-stack`, together with a bare Git repository that carries the holder's snapshots. Each daemon writes its heartbeat and queue changes there; only the daemon of the account that runs the stack writes to the stack's checkout. No account reads another account's home folder. The plugin runs `git` on the daemon host.

New Claude, Codex and OpenCode agents get `stack_join`, `stack_status` and `stack_release` tools from a local MCP server the plugin adds to their sessions; Claude and Codex agents created after installation have them preapproved. Tool replies and the queue show agent titles, workspace names, branches and account names to the agents and to every account that can read the shared folder. Each daemon's app shows the queue on a Shared stack screen.
